# Inmobiliaria — Fase 1

## Cómo correrlo localmente

1. `npm install`
2. Copiar `.env.local.example` a `.env.local` y completar con tus datos de Supabase.
3. `npm run dev`
4. Abrir http://localhost:3000

Por ahora las páginas de propiedades y admin son placeholders: se completan en las próximas fases.
